# Sequia ☁️

Sequia is a beginner-friendly platform for people who are learning how to contribute to Open Source projects. With simple guides and tutorials, they can code with no problems to projects.

# Our Goals 🎯

As well as helping beginners on contributing to Open Source projects, we help each other (via reading our code of conduct) not to be really strict or rude with the community. 

We also offer guides about:

- Simplifying Git and GitHub basics
- Do's and Dont's when creating a repository
- Practice adding their ideas to this repository (adding PRs and issues) **Visit the contributing page   for more details**

***Want to add your explanations? Go for it!***
